# zivotvysvetlen.cz

Statický web Akademie Život vysvětlen. Zatím jedna stránka: interaktivní mapa Akademie.

- `index.html` — mapa, generuje se z `~/Work/skool/export-do-skoolu/mapa-akademie.html`
- `mapa/` — obrázky (obálky modulů a náhledy)
- `CNAME` — doména pro GitHub Pages

Po změně mapy v Akademii: přegenerovat `_mapa-prestav.py`, zkopírovat sem a pushnout.
